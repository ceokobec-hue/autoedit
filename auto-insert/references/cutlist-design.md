# 컷리스트 설계 규칙

## 밀도와 길이

| 항목 | 값 | 왜 |
|---|---|---|
| 컷 밀도 | **30초에 한 컷** (24분 → 45~50컷) | 38컷·49컷짜리 회차에서 검증된 리듬 |
| 컷 길이 | **4~8초** | 8초를 넘으면 화면이 오래 멈춰 지루하다 |
| 움직임 종료 | **컷 길이 − 1.2초 안** | 나머지는 완전 정지(프리즈홀드). 편집에서 길이를 늘려도 안 흔들린다 |
| 컷 간 최소 간격 | 없음. 단 **겹치면 안 됨** | 겹치면 앞 컷을 짧게 자른다. 2.5초면 움직임이 끝나므로 뒤를 잘라도 무해 |

## 무엇을 인서트로 만들 것인가

강사가 **말로만 지나가는 것 중 그림이 있으면 확 쉬워지는 것**을 고른다.

| 넣는다 | 안 넣는다 |
|---|---|
| 장면·비유 (그 회차에서 반복해 쓰는 그림) | **강사가 판서로 쓰는 단어** — 세 번 겹친다 |
| 목록·대조 (색 라벨 3종, ✕/○ 비교) | 대사를 그대로 옮긴 문장 |
| 계보·단계 (domus→domain) | 근거가 불확실한 사례 — 그림까지 붙이면 단정하는 모양이 된다 |
| 누적되는 사례 (참사 4종) | 자막만으로 충분히 이해되는 대목 |
| 숫자·규격 (A4 세 장, 5억 원) | |

## 화면 글자 쓰는 법

**대사를 복제하지 않는다.** 같은 말을 귀로 듣고 눈으로 읽으면 오히려 안 읽힌다.

```
대사  「자, 여기 아주 똑똑한 일꾼이 하나 있다고 쳐 봅시다」
화면  핵심 낱말                          ← 요약된 명사
      세상의 모든 지식을 가진 사람      ← 한 줄 보충
```

- kicker(작은 라벨) → hero(큰 문구 1~2줄) → rule → sub(한 줄) 순서로 눈이 흐른다
- hero는 **8자 이내 × 2줄**까지. 넘으면 줄이 깨진다
- 핵심 텍스트는 **화면 위쪽 900px(1080p 기준) 안**에 둔다. 아래는 자막 자리다

## 레이아웃 5종

47컷을 손으로 쓰면 용어가 어긋난다. **데이터 배열 + 생성기**로 만들고, 레이아웃은 이 다섯 가지로 끝낸다.

| 레이아웃 | 쓰는 곳 | 데이터 |
|---|---|---|
| **hero** | 한 문장으로 못 박을 때 | `k` 라벨 · `h[]` 큰 문구 1~2줄 · `sub` |
| **list** | 항목 2~4개 나열 | 위 + `it[{t,d,n?,c?}]` (제목·설명·번호·색) |
| **vs** | 좌우 대조, ✕/○ | 위 + `it[2]` |
| **chain** | 단계·계보 4칸 + 화살표 | 위 + `it[4]`, 마지막에 `hl:1`로 도착점 강조 |
| **stack** | 사례가 하나씩 쌓일 때 | 위 + `it[]` 가로 전폭 행 |

**색 강조**는 `c:'#D8402A'` 로 준다. 카드 왼쪽에 색 띠가 들어가고 제목도 그 색이 된다. 「빨강·노랑·파랑」처럼 색 자체가 내용일 때 반드시 쓴다 — 안 쓰면 전부 크림색 카드가 되어 의미가 죽는다.

## 스타일 배분

시리즈가 두 스타일을 혼용한다면(예: 종이극장 + 손끝 브리핑):

- **이야기가 굴러가는 컷 = 어두운 쪽**, **정보를 나열하는 컷 = 밝은 쪽**
- 화면 밝기만으로 "지금 무슨 시간인지"가 구분된다
- 목록형이 몰리는 구간(보통 후반)은 **어두운 컷을 두세 장 끼워** 단조로움을 깬다

## 삽입 지점 고르기

- 반드시 **SRT 큐의 시작 시각**을 쓴다. 큐 경계는 강사가 숨 쉬는 지점이라 어색하지 않다
- 문장 한가운데는 안 된다
- 「출발할게요」「뭐냐면 이겁니다」처럼 **강사가 직접 신호를 주는 자리**가 최고의 앵커다. 카드가 그 말에 정확히 떨어진다

## 정합성 검사 (진행 전 필수)

1. 덮어쓰기 구간끼리 겹치는가
2. 범퍼 삽입점이 인서트 구간 **내부**에 떨어지는가 — 떨어지면 인서트가 반으로 잘린다
3. 보호 구간을 침범하는가

**하나라도 걸리면 진행하지 않는다.** 앞 컷을 짧게 자르거나 삽입점을 옮겨 해소한 뒤 다시 검사한다.
