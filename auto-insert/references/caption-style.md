# 자막 규격 — 네 층 · 세로 예산 · 결재 이력

자막은 **한 파일(ASS)에 네 층을 함께 굽는다.** 나중에 한 층을 따로 얹으면 자막→범퍼를 통째로 다시 돌려야 한다.

| Layer | 내용 | 만드는 곳 |
|---|---|---|
| 0 | 배경 박스 — 줄마다 글자 폭에 맞춘 사각형 | `\p1` 드로잉 |
| 1 | 하단 키워드 띠 — 시리즈 진행 위치 (인서트 구간 자동 숨김) | `\p1` + 텍스트 |
| 2 | 자막 글자 — 강조어는 인라인 색 태그 | `Base` 스타일 |
| 3·4 | 말풍선 — 회차당 2~3회 | `\p1` + 텍스트 |

전부 `scripts/make_ass.ps1` 하나가 만든다.

---

## 고정하지 않는 것 · 고정하는 것

**색·글자체·크기는 회차마다 결재받는다.** 화면이 다르고 입은 옷이 다르다 → `scripts/style_gate.ps1`

**구조는 고정이다.**

```
PlayResX 2560 / PlayResY 1440 / WrapStyle 2 / ScaledBorderAndShadow yes
Alignment 2 (하단 중앙)   MarginL/R 140   MarginV 96   Outline 8   Shadow 0
배경 박스: 좌우 패딩 28 · 블록 위아래만 10 깎기 · 불투명도 80%
```

`WrapStyle 2`는 **`\N`에서만 줄을 바꾼다**는 뜻이다. 자동 줄바꿈에 맡기면 배경 박스를 어디에 그릴지 알 수 없다.

---

## 줄 나눔 — 우리가 정한다

폭은 **폰트 파일의 advance width를 직접 읽어** 잰다(`Get-TextWidth`). 브라우저를 띄우지 않는다.

- **Pretendard 한글 advance = 0.864em** — 1.0em으로 어림하면 두 줄 비율을 몇 배로 과대추정한다(추정 27% ↔ 실측 3.4%)
- 줄높이 = `GlyphTypeface.Height` × 크기 = **1.19287 × 크기**
- 한 줄 최대 = 2560 − 140×2 = **2280px** → 130px 기준 한 줄에 약 20자

두 줄이 되면 어절 단위로, **두 줄 폭이 가장 비슷해지는 곳**에서 자른다.

**배경 박스는 블록의 맨 위·맨 아래만 10px 깎는다.** 줄 사이를 깎으면 두 줄 박스 사이에 틈이 생긴다.

---

## 세로 예산 — 인서트 카드와 부딪히는 자리

```
두 줄 자막 블록 상단 = 1440 − MarginV − 2 × (크기 × 1.19287)
```

| 크기 | 두 줄 상단(1440 기준) | 1080 환산 | 인서트 카드 하단은 |
|---|---|---|---|
| 120 | 1058 | 793 | ≤ 773 |
| 130 | 1034 | 776 | ≤ 756 |
| 140 | 1010 | 758 | ≤ 738 |
| 147 | 993 | 745 | ≤ 725 |

**인서트 엔진의 카드 위치를 이 표에 맞춰 잡는다.** 한 번은 자막을 147px로 올렸다가 카드(y1120)를 파고들어 47컷을 전면 재렌더했다.

키워드 띠는 **두 줄 기준 위치에 고정**한다 — 자막 줄 수에 따라 오르내리면 산만하다.

---

## 강조 — 띠가 아니라 글자색

```
{\c&H4BC2FF&}에이전트{\c}        ← BGR 순서. \c 단독은 스타일 기본색 복귀
```

**띠(형광펜)는 폐기했다.** 띠를 그리려면 줄 폭과 강조어 offset을 계산해야 하는데, 몇 px만 어긋나도 **옆 글자를 침범한다**(실측 지적). 색은 계산할 좌표가 없다.

부수 효과로 브라우저 실측(`measure.html` + Playwright + `document.fonts.check()`) 다섯 단계가 통째로 사라졌다.

`pick_emphasis.ps1`은 **무엇을 강조할지만** 정한다. 좌표를 안 쓰므로 예전의 「순수 한글만 · 30자 넘는 큐 제외」 제한은 풀었다.

## 큐 최소 병합

받은 SRT는 시간 기준으로 기계적으로 잘려 「AI ／ 에이전트에게」처럼 **한 낱말이 두 큐로 갈라진다.** 그 자리만 붙인다 — 리듬과 타이밍은 건드리지 않는다.

붙이는 경우는 둘뿐이다.
- **조사 분리** 「결과물 ／ 을 만들어」 — 다만 `이·가·은·는·도·만·로·서`는 **뺀다.** 관형사·부사와 글자가 겹쳐 「말한 ／ 이 다섯 가지를」처럼 멀쩡한 경계를 붙인다
- **복합어** 「AI ／ 에이전트」 — 앞조각만 보면 「데이터 ／ 아니면」이 걸린다. 반드시 **쌍으로** 본다

실측 예: 938큐 → 929큐(9건). 전부 「AI／에이전트」처럼 **복합어가 갈린 자리**였다.

**붙인 목록을 로그로 남긴다.** 오탐은 목록을 봐야 잡힌다 — 처음 넓게 잡았을 때 31건 중 상당수가 오탐이었고, 로그가 없었으면 그대로 나갔다.

## 글자체 조달

폰트 파일은 저장소에 넣지 않는다(라이선스가 제각각이다 → [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)).

**맥에서는 스크립트 한 줄이면 끝난다.**
```bash
bash auto-insert/scripts/mac/get_fonts.sh          # → ~/.autoedit/fonts
```

윈도우에서 손으로 받으려면(폴더는 `$env:AUTOEDIT_FONTS` 로 정한 곳):
```powershell
$d=$env:AUTOEDIT_FONTS
iwr 'https://cdn.jsdelivr.net/npm/pretendard@1.3.9/dist/public/static/Pretendard-Bold.otf'      -OutFile "$d\Pretendard-Bold.otf"
iwr 'https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/gothica1/GothicA1-Black.ttf'             -OutFile "$d\GothicA1-Black.ttf"

# 네이버 나눔글꼴 — zip 안에 Lt/Rg/Bd/Eb/Hv 정적 웨이트가 OTF·TTF 로 다 들어 있다
iwr 'https://hangeul.naver.com/hangeul_static/webfont/zips/nanum-square-neo.zip' -OutFile "$env:TEMP\nsn.zip"
Expand-Archive "$env:TEMP\nsn.zip" "$env:TEMP\nsn" -Force
Copy-Item "$env:TEMP\nsn\**\NanumSquareNeoOTF-Eb.otf" "$d\NanumSquareNeo-ExtraBold.otf"
```

네이버 글꼴은 `hangeul.naver.com/fonts` 에서 「글꼴 다운받기」를 누르면 위 zip URL로 받는다. slug는 카드의 CSS 클래스와 같다(`nanum-square-neo`, `nanum-square`, `nanum-barun-gothic` …). **Playwright로 한 번 눌러 URL을 잡아 두면 다음부터는 직접 받으면 된다.**

| 글자체 | 한글 advance | 성격 | 주의 |
|---|---|---|---|
| Pretendard | 0.864em | 좁아서 한 줄에 많이 들어간다 | Bold·Black이 같은 패밀리 |
| **NanumSquare Neo ExtraBold** | 0.948em | **자막 표준에 가장 가깝다.** 획이 곧고 굵기가 과하지 않다 | 웨이트 5종 중 Eb(800)만 설치 — Hv(900)는 자막에 과하다 |
| Gothic A1 Black | 1.020em | 굵고 정직. 한 줄에 덜 들어간다 | — |
| Black Han Sans | 0.835em | 임팩트 강함. 제목에 가깝다 | **`—` 없음** |
| Jua | 0.830em | 둥글고 친근 | **`—` `‘’` 없음** |

★ 나눔글꼴은 같은 패밀리에 웨이트가 5종이라 **원하는 굵기 하나만 폴더에 둔다.** 여러 개를 두면 게이트가 「가장 굵은 것」을 골라 Heavy가 잡힌다.

**⚠️ `fonts.googleapis.com/css`에 구형 User-Agent로 받으면 서브셋(24~44KB)이 온다.** 한글이 거의 없다. 반드시 위 CDN 경로로 **전체 파일**(1~2MB)을 받는다.

`style_gate.ps1`에 `-Srt`를 주면 **그 회차 자막에 실제로 쓰이는 글자를 전 폰트에 대해 검사**해, 빠진 글자가 있는 후보에 경고를 달고 뒤로 보낸다. 빠지면 화면에 □가 뜬다.

## 결재 이력 — 이 표를 «여러분 것으로» 채워 나간다

회차마다 무엇을 골랐고 어떤 피드백을 받았는지 쌓는다. **다음 회차 후보를 여기에 맞춰 좁힌다.**
아래 두 줄은 **어떻게 쓰는지 보여주는 예시**다. 지우고 본인 회차로 채워 쓰면 된다.

| 회차 | 크기 | 배경 | 강조 | 글자체 | 받은 피드백 |
|---|---|---|---|---|---|
| 1회차 (초판) | 69 | 없음 | 형광펜(미반영) | Pretendard | **너무 작다** |
| 1회차 v2 | 147 | 브라운 #2A1E1A 80% | 형광펜 노랑 | Pretendard | **너무 크다**(120~130이 적당) · **형광펜이 자간을 넘는다** · 배경·불투명도는 좋았다 · 단어가 쪼개져 보인다 · 타이밍 미세 오차 |
| 2회차 | 130 기준으로 게이트 | 의상 톤온톤 우선 | 앰버 #FFC24B | — | (제작 후 기록) |

**이력이 쌓일수록 게이트가 내미는 후보가 좁아진다.** 그게 이 표의 값어치다.

**타이밍**이 계속 걸리면 Whisper 단어 단위 정렬로 큐 경계를 갈아끼운다(25분 영상 CPU 전사 20~40분).
