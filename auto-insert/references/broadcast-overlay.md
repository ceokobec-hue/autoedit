# 방송형 오버레이 — 배경이 계속 바뀌는 영상용

야외 촬영·이동 촬영처럼 **배경이 계속 바뀌는 영상**은 풀프레임 인서트만으로는 안 맞는다.
방송국 화면 문법으로 간다 — **좌상단 채널 버그 + 단원 소제목 + 어깨 옆 카드(OTS)**.

> 스튜디오 강의(고정 배경)는 기존 풀프레임 방식(`cutlist-design.md`)을 그대로 쓴다.

## 화면 3요소

| 요소 | 규격 | 만드는 도구 |
|---|---|---|
| **채널 버그** | 좌상단 (64,46) 반투명 검은 판(alpha 0x6C) + 레드 세로바 9×48 + 채널명 42px · **0초~끝 상시** | `broadcast_overlay.py` → ASS |
| **소제목** | 버그 아래 30px · **단원 단위로만** | 같은 ASS · 페이드인 300ms |
| **인서트컷** | **코너 카드**(영상 보이며 옆에) / **풀프레임**(화면 전체) — 둘 다 모션그래픽, 「화면을 덮느냐」만 다르다 | `build_inserts.py` → Chrome 스크린샷 |

⚠️ **판 폭은 폰트 폭으로 실측**한다(`srt_tools.get_text_width`). 고정폭이면 긴 소제목이 판 밖으로 나간다.
⚠️ **소제목은 단원 단위.** 20분에 9개 정도. 촘촘하면 산만하다 — 25개를 넣어 봤다가 「너무 많다」는 지적을 받고 단원별로만 남겼다.

## ★ OTS 배치 규칙 — 이게 핵심이다

**얼굴만 절대 회피한다(여유 25%). 어깨는 덮어도 된다.**
방송 뉴스의 OTS 그래픽이 원래 어깨를 덮는다. ⛔어깨까지 피하면 셀피 영상에서 카드가 680px로 쪼그라든다
(실측: 어깨 회피 → 최대 680×510 / 얼굴만 회피 → 780~1080px).

**회피 대상**
1. 얼굴 박스 + 폭의 25% 여유
2. 얼굴을 못 찾으면 사람 박스의 **상단 45%**만
3. **화면 위 글자 전부(높이 60px 이상)** — 편집자가 넣은 강조자막 · 강의장 슬라이드
   ⛔이걸 빼먹으면 **이미 넣어 둔 강조자막 위에 카드가 얹힌다**(실제로 당했다).
   검출되는 모양의 예: 가로 강조자막 h227 · h204 · 세로 기울임 자막 h981
   — **높이(h)로 거른다.** 본 자막보다 큰 글자는 편집자가 넣은 것이다

**세로 가용 범위** = 소제목 아래(210px) ~ **구워진 자막 윗변**
자막 윗변은 **글자 y 히스토그램**으로 잡는다 — 100px 구간으로 세어 하단에서 가장 자주 나오는 띠.
⛔단순 `min(y)`는 슬라이드 글자를 자막으로 오인한다(실측 867px로 잘못 잡혀 카드가 반으로 줄었다. 실제 1206px).

**자리를 못 찾으면**
① 시각을 **최대 15초까지 민다**(대사 구간 안이면 카드가 늦게 떠도 자연스럽다)
② 그래도 없으면 **풀프레임으로 승격**한다
③ 승격분은 **원고를 3항목으로 보강**할 것 — 코너 원고를 그대로 올리면 화면 아래가 텅 빈다

**풀프레임 고스트 숫자는 시간순 통번호.** 원고에 박힌 번호를 쓰면 승격분과 겹친다.

## 공정

```
① 원고        cards.json  (id·kind·at·dur·kicker·head·rows/desc·foot·src)
② 배치        ots_place.py    스팬별 프레임 샘플 → Vision → 코너/크기/시각 확정
③ 생성        build_inserts.py  HTML → Chrome 스크린샷 (코너=알파 PNG · 풀=불투명 PNG)
④ 버그·소제목  broadcast_overlay.py --chapters ch.json --end <초> → overlay.ass
⑤ 🙋검수      review_sheet.py   전체 렌더 없이 프레임만 구워 번호표
⑥ 최종        render_final.py   한 패스(ASS + 오버레이 전부)
```

## 검수 게이트 (상시 · 건너뛰지 않는다)

**얹은 것 전부를 스크린샷으로 먼저 보고, 승인한 뒤에 최종 렌더한다.**

- **전체 렌더 없이** 필요한 프레임만 굽는다 → 몇 번을 고쳐도 금방 다시 뽑는다
- 번호표는 **우상단**. ⛔좌상단은 채널 버그 자리라 가리면 검수가 안 된다
- 「4번, 17번 고쳐」처럼 번호로 지적 → 수정 → 재발행 → **명시 승인 후에만** 최종 렌더

## 렌더는 한 패스로

세대가 쌓이면 화질이 깎이고 QHD 중간본이 디스크를 먹는다.
`subtitles`(버그·소제목) → `overlay` 체인(인서트 전부)을 **한 번에** 건다. 풀프레임도 불투명 오버레이면 된다.

```
ffmpeg -i src.mp4 -i c01.png ... -filter_complex
  "[0:v]subtitles=overlay.ass:fontsdir=...[v0];
   [v0][1:v]overlay=X:Y:enable='between(t,a,b)'[v1]; ..."
  -c:v h264_videotoolbox -b:v 24M -c:a aac
```

## HTML → PNG (Chrome 헤드리스)

```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --default-background-color=00000000 --screenshot=out.png --window-size=W,H "file://$PWD/card.html"
```
⚠️ **알파를 얻으려면 카드 주변에 여백**을 둬야 한다(캔버스 = 카드 + 여백 80px×2, 카드는 flex 중앙).
카드가 창에 딱 맞으면 Chrome이 `rgb24`로 내보내 드롭섀도우가 잘린다.
