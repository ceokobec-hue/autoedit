# pipeline_v2 — 화면공유+얼굴PIP 영상에 카드 얹기

**화면공유(엑셀·터미널·폴더) + 우상단 얼굴 PIP** 형태의 영상에 특화된 한 벌이다.
QHD 22분·카드 72장짜리를 **끝까지 완주하며** 만들었다.
기존 `../` 의 도구를 대체하지 않는다 — 대상이 다르다.

## 왜 따로 있나
| | `../` 기존 | **pipeline_v2** |
|---|---|---|
| 대상 | 스튜디오 강의 · 브이로그 | **화면공유 + 얼굴 PIP** |
| 자리 판정 | `ots_place.py` (스팬 단위) | `place.py` — 금지구역·강등체인·시각밀기·카드종류별 기준 |
| 결재 | `review_sheet.py` | **2단** — 검토 게이트(영상 없이) → 검수 게이트(진짜 화면에 얹어) |

★ **얼굴 검출기는 새로 만들지 않았다.** `../speaker_box.swift` 를 그대로 쓴다
(얼굴·사람에 더해 **화면 글자 OCR** 까지 준다).
한때 그 파일을 못 읽어 똑같은 걸 새로 짰다가 폐기한 적이 있다 — **정본을 못 읽으면 중복을 만든다.**

# 실행

## 준비

```bash
cd ~/Downloads/autoedit                       # ★ 저장소 폴더
PY=~/.autoedit/venv/bin/python
S=$PWD/auto-insert/scripts/mac/pipeline_v2    # ← 절대경로로 잡는다 (작업 폴더로 옮겨 갈 것이므로)

mkdir -p ~/pipe-work && cd ~/pipe-work        # 결과물이 여기 쌓인다 (영문 경로)
cp $S/job.example.json ./job.json             # 그리고 job.json 을 내 것으로 고친다
```

`job.json` 에 뭘 적는지는 [`파일형식.md`](../../../../파일형식.md) 를 본다.
`sub_band`·`pip`·`bug_zone` 좌표는 **눈대중으로 넣지 말고 재서** 넣는다.

```bash
$PY $S/measure_layout.py                      # 화면 구조(자막 띠·글자 위치)를 잰다
$PY $S/measure_pip.py                         # 얼굴 작은 화면 자리를 잰다
```

## 순서대로

```bash
$PY $S/build_cards.py               # ① 대본 → 컷 원고 + 정합성 검사   → cards.json
$PY $S/build_sheet.py               # ② 검토 게이트 HTML  🙋 사람이 본다
$PY $S/build_bug.py                 # ③ 채널 버그 + 단원 소제목 (폰트 폭 실측)
$PY $S/place.py                     # ④ 컷마다 프레임 재서 자리 결정   → placement.json
$PY $S/fix_overlaps.py              # ⑤ ★자리 판정 «후» 겹침 해소      → durations.json
$PY $S/build_png2.py                # ⑥ 카드 PNG (Chrome 3회로 전부)
$PY $S/build_check.py               # ⑦ 검수 게이트 HTML  🙋 사람이 승인
$PY $S/render_overlays.py --test    # ⑧ 60초 시험 → 프레임 뽑아 «진짜 보이나» 확인
$PY $S/render_overlays.py           # ⑨ 최종
```

모든 스크립트가 **지금 폴더의 `job.json`** 을 읽는다. 그래서 인자가 거의 없다.
`job.json` 이 없으면 어디에 뭘 만들라고 한국어로 알려 주고 멈춘다.

> ⛔ **⑧ 를 건너뛰지 않는다.** 60초만 굽는 데 몇십 초면 되고,
> 「카드가 에러 없이 안 보이는」 사고를 여기서 잡는다. 최종 렌더는 10분 단위로 걸린다.

## ⛔ 여기서 실제로 터진 것 (전부 겪음)

1. **정지 PNG 에 fade → 카드가 «에러 없이» 안 보인다.** 오버레이 입력은 `-loop 1 -framerate 30 -t` 로 진짜 시간축을 줘야 한다.
2. **얹을 층은 전부 먼저 확정하고 자리를 잡는다.** 채널 버그를 나중에 넣어 카드 19장이 그 위에 얹혔다.
3. **시각을 민 뒤 겹침을 다시 검사한다.** 처음 시각으로만 통과시켜 4건이 겹쳤다.
4. **«같은 시간 + 같은 자리» 충돌도 본다.** 두 카드가 같은 좌표라 오프닝 타이틀이 사라졌다.
5. **저장은 원자적으로.** `open(p,'w')` 는 실패해도 원본을 이미 비운다 → `job.save_atomic()`.
6. **렌더 전 프리플라이트.** `rm -rf png` 이 다른 스크립트 산출물(`bug.png`)까지 지워 렌더가 죽었다.
7. **ffmpeg 9 는 `-filter_complex_script` 없음.** 인라인으로 넘긴다.
8. **Chrome 콜드 스타트 ~35초.** 장당 실행 금지 — 한 페이지에 쌓아 굽고 `crop` 으로 잘라낸다.

## 참고 실측 (M1 8GB 랩톱 · QHD 22분 · 오버레이 82장)

여러분 맥에서는 다르게 나옵니다. **감을 잡는 용도**입니다.

디코딩 24% · **인코딩 37%** · 카드 얹기 39% · 전체 약 10분.
ffmpeg 이 쓴 CPU 는 8코어 중 2.2개.

⛔ `-hwaccel videotoolbox` 는 **오히려 2배 느리다**(메모리 복사가 더 비싸다).
⛔ 그래픽카드 등급과 무관하다.
